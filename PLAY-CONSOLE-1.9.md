# Play Console — SHAMS 1.9.0

1. Internal testing-də **SHAMS-1.9.0-play.aab** seçin: paket `com.shams.play`, versiya kodu 21. Əgər Console-da 21 də artıq istifadə edilibsə, yeni yığımda daha böyük kod lazımdır. AAB telefona birbaşa quraşdırılmır; APK test üçündür.
2. `shams_premium_yearly` məhsulunu və birillik auto-renewable base planı aktivləşdirin. Nəzərdə tutulan USD qiyməti $3.50-dir; tətbiq qiyməti mağazadan dinamik oxuyur. Gerçək base plan ID-sini Supabase `PLAY_BASE_PLAN_ID` kimi daxil edin.
3. Android Publisher API xidmət hesabını yaradın, yalnız bu tətbiqin alış/abunəlik idarəsi hüquqlarını Play Console-da verin. JSON açarı yalnız Supabase Secrets-ə `PLAY_SERVICE_ACCOUNT_JSON` kimi daxil edilir; `PLAY_PACKAGE_NAME=com.shams.play` olmalıdır. `STORE_TOKEN_KEY` alış tokenlərinin server şifrələməsi üçün lazımdır. Məxfi fayllar GitHub-a və APK-yə daxil edilməməlidir.
4. RTDN: Pub/Sub topic, Google Play publish icazəsi və authenticated push subscription qurun. URL: `https://ayaiddowrabrdltrqysn.supabase.co/functions/v1/store-billing`. `PLAY_RTDN_AUDIENCE` və `PLAY_RTDN_SERVICE_ACCOUNT_EMAIL` uyğun olsun. Reconcile cron və `STORE_CRON_SECRET` quraşdırın. Faktiki komissiya yoxdursa maliyyə qeydi admin təsdiqində qalmalıdır; demo satış əlavə edilmir.
5. License Testing + Internal testing istifadəçiləri əlavə edin. Play-dən quraşdırılmış paketdə alış, pending, ləğv, bərpa, renewal, refund və expiry yoxlamalarını keçirin. Sandbox üçün yalnız serverdə `ALLOW_STORE_SANDBOX=true` ilə ayrıca test edin. Bu əməliyyatların real testi bu kompüterdə aparılmayıb.
6. AdMob Google hesabında Azərbaycan telefon nömrəsini təsdiqləyin. SHAMS Android tətbiqini qeydiyyatdan keçirin, banner App/Ad Unit ID-lərini alın; UMP Privacy & messaging formasını yaradın. Real reklam yığımı üçün `SHAMS_ADMOB_APP_ID`, `SHAMS_ADMOB_BANNER_ID` və `build-store.ps1 -AdsMode production` lazımdır. `test` rejimi yalnız rəsmi Google test ID-lərindən istifadə edir; əsas AAB-də `off` seçilib. Reklam rejimi dəyişəndə yeni versionCode ilə yenidən buraxın.
7. Data safety/Ads bölmələrini məhz yüklədiyiniz paket və aktiv xidmətlərə uyğun doldurun. SDK paketdə Ad ID icazəsini gətirir; reklamlı yığıma keçərkən Google reklam məlumat kateqoriyalarını nəzərə alın. Məxfilik: `https://mubaristi-create.github.io/basira/privacy.html`; silmə: `https://mubaristi-create.github.io/basira/deletion.html`. Tərtibatçı SHAMS, dəstək mubaristi@gmail.com.
8. Pre-launch report və fiziki telefonlarda Android 10–16, gesture/3-button, klaviatura, böyük şrift, cutout/landscape, restartdan sonra azan və widget sınaqlarını tamamlayın. Hədis kitabxanası və ayrıca qəza namazı modulu mövcud olmayan funksiyalar kimi qeyd edilir.

Google OAuth layihəsi: SHAMS (`oceanic-toolbox-514121-p8`). Supabase callback: `https://ayaiddowrabrdltrqysn.supabase.co/auth/v1/callback`; native geri dönüş: `com.shams.play://auth/callback`. Client secret yalnız private-data və Supabase-dədir, release arxivində yoxdur. OAuth production/audience və real istifadəçi giriş testi ayrıca təsdiqlənməlidir.
